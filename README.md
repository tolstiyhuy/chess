# ♞ Шахматы

Полноценные шахматы в стиле chess.com — играйте с другом по сети, вдвоём за одним компьютером или против бота. Без установки, без сборки и без интернета для локальных режимов.

## Быстрый старт

**Самый простой способ:** дважды кликните `start.bat` — игра откроется по адресу `http://localhost:8000`.

Вручную:

```bash
node server.js          # или
python -m http.server 8000
```

Затем откройте `http://localhost:8000`.

Для режима **«Локальная сеть»** нужен Node.js — `start.bat` запускает его автоматически. Без Node.js (только Python) работают офлайн-режимы и P2P-игра через интернет.

Можно открыть и просто `index.html` двойным кликом — локальная игра и бот заработают, но для игры по сети лучше использовать сервер (некоторые браузеры ограничивают WebRTC на `file://`).

## Как играть с другом по сети

В онлайн-режиме есть два способа связи — переключатель **«Способ связи»** над кнопкой запуска.

### Вариант 1. Интернет (P2P, по умолчанию)

Нужен только браузер и интернет, сервер не требуется.

1. Откройте игру у себя (можно просто двойным кликом по `index.html`, но надёжнее — через `start.bat` или хостинг).
2. Вкладка **«Онлайн»** → способ связи **«Интернет»** → **«Создать комнату»**.
3. Появится код из 5 символов, например `K7QX2`. Отправьте другу **ссылку на игру и код**.
4. Друг открывает ту же страницу, вводит код в поле **«Код комнаты»** и нажимает **«Войти»**.
5. Игра начинается: у каждого свой цвет, часы идут, ходы синхронизируются.

Как это работает: браузеры соединяются напрямую по WebRTC, а знакомятся через публичные WebTorrent-трекеры ([Trystero](https://github.com/dmotz/trystero)). Ходы не проходят через игровой сервер.

Чтобы друг открыл ту же страницу из интернета, выложите папку `chess` на бесплатный статический хостинг (GitHub Pages, Netlify, Cloudflare Pages, Vercel) — сборка и Node.js не нужны.

### Вариант 2. Локальная сеть (свой сервер)

Надёжнее, если P2P блокируется (корпоративный Wi-Fi, некоторые провайдеры).

1. Запустите `start.bat` (или `node server.js`) на компьютере в той же сети.
2. В окне консоли появится адрес вида `http://192.168.1.10:8000` — откройте его у себя и отправьте другу.
3. Оба выбирают способ связи **«Локальная сеть»**, создают комнату и вводят код.

`server.js` раздаёт файлы и заодно работает WebSocket-ретранслятором комнат: интернет не нужен вообще, только локальная сеть.

Если друг далеко, локальный режим тоже подойдёт — поднимите сервер и откройте к нему доступ через туннель (ngrok, Cloudflare Tunnel), тогда друг заходит по внешнему адресу.

Важно:

- В P2P-режиме обоим нужен современный браузер (Chrome, Edge, Firefox, Safari) и доступ в интернет. В редких сетях WebRTC заблокирован — тогда используйте режим «Локальная сеть».
- Код комнаты живёт, пока открыта вкладка создателя.

## Режимы

| Режим | Что делает |
| --- | --- |
| **Онлайн** | Комната по коду: P2P через интернет или через свой сервер в локальной сети. Часы, чат, ничья, реванш. |
| **На одном устройстве** | Классические шахматы за одним компьютером: ходы по очереди, доска не переворачивается. |
| **С ботом** | Три уровня: новичок, любитель, клубный игрок. Можно выбрать цвет. |

## Возможности

- Полные правила: рокировка, взятие на проходе, превращение пешки, мат, пат, ничья по 50 ходам, недостаточному материалу и троекратному повторению.
- Часы с добавлением времени, флажок засчитывается автоматически.
- Перетаскивание фигур и ходы кликом, подсветка доступных полей, последнего хода и шаха.
- Список ходов в нотации SAN, просмотр партии стрелками (← → Home End), кнопка «Перевернуть доску».
- Копирование PGN и FEN в буфер обмена.
- Чат в онлайн-партии, предложение ничьей, сдача, реванш с обменом цветами.
- 4 темы доски, синтезированные звуки (без аудиофайлов), отключение звука.
- Адаптивная вёрстка для компьютера и телефона.

## Управление

- **Мышь / палец:** перетащите фигуру или кликните по ней, затем по полю.
- **← / →** — назад/вперёд по ходам, **Home / End** — в начало/конец.
- **F** — перевернуть доску.
- **Esc** — закрыть диалог.

## Тесты

```bash
node test/engine.test.js
node test/ws.test.js
```

Первый проверяет perft-позиции (начальная, kiwipete, позиции с рокировкой, взятием на проходе и превращением), SAN, определение мата и обратимость FEN. Второй поднимает `server.js` на отдельном порту и прогоняет создание комнаты, подключение второго игрока, передачу сообщений в обе стороны, отказ третьему игроку и уведомление об отключении.

## Ограничения

- Нет серверной проверки ходов и античита: в онлайн-партии доверие строится на клиенте. Играйте с друзьями.
- Коды комнат живут, пока открыта вкладка создателя.
- P2P-режим зависит от публичных сигнальных трекеров и WebRTC — в некоторых сетях он недоступен. Для таких случаев есть режим «Локальная сеть».
