# ♞ Шахматы

Полноценные шахматы в стиле chess.com — играйте с другом по сети, вдвоём за одним компьютером или против бота. Без установки, без сборки и без интернета для локальных режимов.

**Играть онлайн прямо сейчас: https://tolstiyhuy.github.io/chess/** — откройте ссылку, нажмите «Создать комнату» и отправьте другу код.

## Быстрый старт

**Самый простой способ:** дважды кликните `start.bat` — игра откроется по адресу `http://localhost:8000`.

Вручную:

```bash
node server.js          # или
python -m http.server 8000
```

Затем откройте `http://localhost:8000`.

Для режима **«Локальная сеть»** нужен Node.js — `start.bat` запускает его автоматически. Без Node.js (только Python) работают офлайн-режимы и онлайн-игра через интернет.

Можно открыть и просто `index.html` двойным кликом — локальная игра, бот и онлайн через интернет заработают. Режим «Локальная сеть» требует запущенного `server.js`.

## Как играть с другом по сети

В онлайн-режиме есть три способа связи — переключатель **«Способ связи»**. По умолчанию выбран самый надёжный — **«Через сервер»**.

### Вариант 1. Через сервер (по умолчанию)

Ничего устанавливать не нужно: оба игрока подключаются к публичному серверу-ретранслятору и обмениваются ходами в комнате.

1. Откройте игру (https://tolstiyhuy.github.io/chess/ или свой хостинг).
2. Вкладка **«Онлайн»** → способ связи **«Через сервер»** → **«Создать комнату»**.
3. Появится код из 7 символов, например `K7QX2NM`. Отправьте другу **ссылку на игру и код**.
4. Друг открывает ту же страницу, вводит код в поле **«Код комнаты»** и нажимает **«Войти»**.
5. Игра начинается: у каждого свой цвет, часы идут, ходы синхронизируются.

Как это работает: оба браузера держат WebSocket-соединение с публичным MQTT-брокером (EMQX, список запасных — в `js/netrelay.js`) и пишут сообщения в топик `chesstime/v3/<код>`. Соединение не требует WebRTC, проброса портов и своего сервера, поэтому работает почти в любой сети и на мобильном интернете. Код комнаты — единственный «пароль»: он достаточно длинный, чтобы посторонний его не подобрал.

### Вариант 2. P2P (WebRTC, без сервера)

Прямое соединение браузеров через публичные сигнальные трекеры ([Trystero](https://github.com/dmotz/trystero)). Ходы не проходят через посредника, но в некоторых сетях и браузерах WebRTC блокируется — тогда вернитесь на «Через сервер».

### Вариант 3. Локальная сеть (свой сервер)

1. Запустите `start.bat` (или `node server.js`) на компьютере в той же сети.
2. В окне консоли появится адрес вида `http://192.168.1.10:8000` — откройте его у себя и отправьте другу.
3. Оба выбирают способ связи **«Локальная сеть»**, создают комнату и вводят код.

`server.js` раздаёт файлы и заодно работает WebSocket-ретранслятором комнат: интернет не нужен вообще, только локальная сеть. Если друг далеко — откройте доступ через туннель (ngrok, Cloudflare Tunnel) и играйте по внешнему адресу.

Важно:

- Код комнаты живёт, пока открыта вкладка создателя.
- Публичные брокеры — это чужой бесплатный сервис: в редкий момент он может быть недоступен. Тогда переключитесь на другой способ связи и создайте комнату заново.

## Режимы

| Режим | Что делает |
| --- | --- |
| **Онлайн** | Комната по коду: через публичный сервер-ретранслятор (по умолчанию), P2P или свой сервер в локальной сети. Часы, чат, ничья, реванш. |
| **На одном устройстве** | Классические шахматы за одним компьютером: ходы по очереди, доска не переворачивается. |
| **С ботом** | Три уровня: новичок, любитель, клубный игрок. Можно выбрать цвет. |

## Возможности

- Полные правила: рокировка, взятие на проходе, превращение пешки, мат, пат, ничья по 50 ходам, недостаточному материалу и троекратному повторению.
- Часы с добавлением времени, флажок засчитывается автоматически.
- Перетаскивание фигур и ходы кликом, подсветка доступных полей, последнего хода и шаха.
- Список ходов в нотации SAN, просмотр партии стрелками (← → Home End), кнопка «Перевернуть доску».
- Копирование PGN и FEN в буфер обмена.
- Чат в онлайн-партии, предложение ничьей, сдача, реванш с обменом цветами.
- 4 темы доски, синтезированные звуки (без аудиофайлов), отключение звука.
- Адаптивная вёрстка для компьютера и телефона.

## Управление

- **Мышь / палец:** перетащите фигуру или кликните по ней, затем по полю.
- **← / →** — назад/вперёд по ходам, **Home / End** — в начало/конец.
- **F** — перевернуть доску.
- **Esc** — закрыть диалог.


## Тесты

```bash
node test/engine.test.js
node test/mqtt.test.js
node test/ws.test.js
```

Первый проверяет perft-позиции (начальная, kiwipete, позиции с рокировкой, взятием на проходе и превращением), SAN, определение мата и обратимость FEN. Второй подключается к публичному брокеру двумя клиентами и проверяет доставку сообщений. Третий поднимает `server.js` на отдельном порту и прогоняет создание комнаты, подключение второго игрока, передачу сообщений в обе стороны, отказ третьему игроку и уведомление об отключении.

## Ограничения

- Нет серверной проверки ходов и античита: в онлайн-партии доверие строится на клиенте. Играйте с друзьями.
- Коды комнат живут, пока открыта вкладка создателя.
- Режим «Через сервер» зависит от публичных MQTT-брокеров, P2P — от сигнальных трекеров и WebRTC. Если один способ не работает, переключитесь на другой; режим «Локальная сеть» не зависит от интернета вообще.
